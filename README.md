# Budap Finance Control

Публичная версия: https://vpolishko-crypto.github.io/budap-finance-test/

Статическая панель без сборки и внешних библиотек. GitHub Pages публикует корень main.

- index.html — разделы панели.
- assets/ — оформление и интерактивность.
- data/programs.json — условия, источники, даты проверки.
- AGENTS.md — постоянные правила.
- PROJECT_CONTEXT.md — публичный контекст.

Локальный просмотр: python -m http.server 8000 --bind 127.0.0.1
Затем открыть http://127.0.0.1:8000/. Загрузка JSON требует HTTP.

Статусы документов демонстрационные и хранятся только в localStorage браузера. Автоматического мониторинга и ежедневного обновления нет. Перед подачей условия следует перепроверить.
