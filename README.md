# Budap Finance Control

Публічна версія: https://vpolishko-crypto.github.io/budap-finance-test/

Статична панель українською без збирання та зовнішніх бібліотек. GitHub Pages публікує корінь main.

- index.html — огляд.
- strategy.html — стратегія.
- funding.html — фінансування та фільтри програм.
- preparation.html — підготовка документів.
- actions.html — план дій.
- history.html — оновлення.
- assets/ — спільне оформлення та інтерактивність.
- data/programs.json — умови, джерела, дати перевірки.
- AGENTS.md — постійні правила.
- PROJECT_CONTEXT.md — публічний контекст.

Локальний перегляд: `python -m http.server 8000 --bind 127.0.0.1`
Потім відкрити http://127.0.0.1:8000/. Завантаження JSON потребує HTTP.

Статуси документів демонстраційні, зберігаються лише в localStorage браузера. Ключ і порядок документів збережено для сумісності з попередньою версією. Автоматичного моніторингу й щоденного оновлення немає. Перед поданням умови слід перевірити повторно.
