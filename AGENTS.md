# Budap Finance Control: правила

- Цель: панель финансирования производства, подготовки документов и следующих действий.
- Репозиторий и Pages публичны. Только публичные сведения и обозначенные демо-данные. Не добавлять личные профили, обороты, бюджеты бизнеса, банковскую историю, договоры, декларации, реквизиты, секреты и вложения из чата. Полный частный контекст не копировать.
- Архитектура: HTML/CSS/JS/JSON → Git → GitHub Pages из main. VPS и прежний API не использовать. Не выполнять force push.
- Проверять фактический путь и git status; не создавать дубликаты проекта.
- Финансовые условия проверять по официальным источникам. Сохранять ссылки и даты. Отделять условия от оценки применимости. Номинальная ставка не равна полной стоимости. Неизвестные параметры обозначать явно.
- Демо-статусы браузера не являются общей базой и не синхронизируются между устройствами. Ежедневный мониторинг пока не реализован.
- Общаться по-русски, объяснять существенные действия. При необходимости авторизации остановиться. Перед публикацией проверить данные и интерфейс; после push проверить сайт.
