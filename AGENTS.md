# Budap Finance Control: правила

- Мета: панель фінансування виробництва, підготовки документів і наступних дій.
- Увесь інтерфейс, документація та спілкування з користувачем — українською мовою.
- Розділи мають окремі HTML-сторінки зі спільною навігацією та позначенням поточної сторінки. Не повертати формат довгого лендингу без запиту користувача.
- Репозиторій і Pages публічні. Лише публічні відомості та позначені демонстраційні дані. Не додавати особисті профілі, обороти, бюджети бізнесу, банківську історію, договори, декларації, реквізити, секрети й вкладення з чату. Повний приватний контекст не копіювати.
- Архітектура: HTML/CSS/JS/JSON → Git → GitHub Pages із main. VPS і колишній API не використовувати. Не виконувати force push.
- Перевіряти фактичний шлях і git status; не створювати дублікати проєкту.
- Фінансові умови перевіряти за офіційними джерелами. Зберігати посилання й дати. Відділяти умови від оцінки застосовності. Номінальна ставка не дорівнює повній вартості. Невідомі параметри позначати явно.
- Демонстраційні статуси браузера не є спільною базою та не синхронізуються між пристроями. Зберігати сумісність ключа budap-demo-documents-v1 і порядку документів. Щоденний моніторинг ще не реалізовано.
- Пояснювати суттєві дії. За потреби авторизації зупинитися. Перед публікацією перевірити дані та інтерфейс; після push перевірити сайт.
