# Budap Finance Control

Постоянная панель для сравнения грантов, льготных кредитов, оборудования, оборотных средств и программ поддержки производства. Должна показывать требования, подготовку и следующий шаг.

## Архитектура
Репозиторий vpolishko-crypto/budap-finance-test. Pages публикует main из корня. Проверены TEST 1 → TEST 2 и обновление курсов НБУ. Агент изменяет файлы, делает commit/push и проверяет публикацию. VPS не используется.

## Публичная первая версия
Обзор, стратегии действующего и нового бизнеса, программы с источниками, демо-список документов, план действий, история и курсы. Персональные данные и фактические статусы не публикуются. Демо-прогресс не означает реальную готовность бизнеса.

## Дальше
Сначала выбрать приватное хранение, затем добавить два независимых бизнес-профиля, фактическую готовность и бюджеты. Не допускать искусственного дробления бизнеса для обхода условий.

Будущий мониторинг: ежедневная проверка официальных источников → значимое изменение → обновление → публикация → уведомление. Без изменений не нужны commits и уведомления. Автоматизация ещё не настроена.
